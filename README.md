# Check-List Checker

Лёгкое Windows-приложение для отслеживания новых файлов в двух сетевых папках. Сканирует их при запуске и каждый час, показывает toast-уведомление при появлении нового файла, работает в системном трее.

## Возможности

- Сканирование двух папок (включая все подпапки) последовательно: сперва первая, затем вторая
- Авто-скан каждый час + кнопка «Сканировать сейчас»
- Toast-уведомления Windows с именем нового файла
- Кликабельная ссылка в окне открывает Проводник с подсветкой самого свежего нового файла из каждой папки
- При закрытии окна приложение сворачивается в трей; выход — через ПКМ → «Выход»
- Пути папок и список известных файлов сохраняются между запусками (`%APPDATA%\check-list-checker\`)

## Установка

Требуется Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
python main.py
```

При первом запуске:
1. Откроется окно. Нажмите «Выбрать…» рядом с «Папка 1» и/или «Папка 2».
2. Первый скан выбранной папки делает baseline — все существующие файлы запоминаются, **уведомлений нет**.
3. Со следующего скана (через час или по кнопке) уведомления приходят только на действительно новые файлы.

## Сборка в standalone .exe

### Локально

```powershell
pip install pyinstaller
pyinstaller --onefile --windowed --icon=assets/icon.ico `
  --add-data "assets/icon.ico;assets" `
  --name "CheckListChecker" main.py
```

Готовый `dist\CheckListChecker.exe` можно копировать на любую Windows-машину без Python.

### Через GitHub Actions (рекомендуется)

В репозитории настроен workflow `.github/workflows/release.yml`, который
собирает `.exe` на `windows-latest` и публикует его в GitHub Release.

**Чтобы выпустить новую версию:**

```powershell
git tag v1.0.0
git push origin v1.0.0
```

CI запустится, соберёт `CheckListChecker.exe` и автоматически
прикрепит его к Release `v1.0.0`. Пользователи качают по прямой
ссылке со страницы Releases.

**Для пробной сборки без релиза** — запустите workflow вручную
(*Actions → Build release → Run workflow*). Готовый `.exe` останется
в артефактах прогона (хранится 30 дней).

## Где хранится состояние

`%APPDATA%\check-list-checker\`

- `config.json` — выбранные пути папок
- `state.json` — список известных файлов на момент последнего скана
- `icon.ico` — копия иконки приложения (нужна реестру)
- `app.log` — журнал работы (полезен для диагностики таймера)

Также при первом показе уведомления приложение добавляет ключ
`HKCU\Software\Classes\AppUserModelId\ChecklistChecker.App`. Это нужно,
чтобы Windows корректно маршрутизировала нажатие кнопки «Открыть папку»
в нашем тосте.

Чтобы «сбросить» приложение к состоянию первого запуска, удалите папку
`%APPDATA%\check-list-checker\` и при желании этот ключ реестра.
